## 使用规则

1. 首次出现的英文缩写必须写全称；
2. 代码 / Schema 中的字段名以「英文」列为准；
3. 前端与文档文案以「中文」列为准。

## 术语列表

| 中文 | 英文 / 缩写 | 定义 | 系统内使用场景 |
|---|---|---|---|
| 总体设计 | Overall Design / System Design | 整星方案与指标分配 | 任务输出、模块命名 |
| 构型 | Configuration | 卫星外形与布局 | 文档章节 2 |
| 分系统 | Subsystem | 电源/姿控/测控等 | 指标树 |
| 有效载荷 | Payload | 执行任务的主载荷 | 任务书输入 |
| 质量预算 | Mass Budget | 干重 + 推进剂 + 余量 | C1 计算模块 |

| 数据量预算 | Data Budget | 产生量 / 压缩 / 下行 / 存储 | C3 |
| 链路预算 | Link Budget | EIRP / G/T / Eb/N0 / 余量 | C4 |
| 有效全向辐射功率 | EIRP | 发射端等效辐射功率（dBW） | 链路预算字段 |
