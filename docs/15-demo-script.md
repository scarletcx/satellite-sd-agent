## 1. 演示目标

看完演示，观众应能复述：① 系统内部发生了什么；② 数字为什么可信、怎么被验证；③ 无出处数字会怎样。

## 2. 主场景脚本（约 10 分钟）

场景：**「设计一颗 500km SSO 光学遥感小卫星」**（黄金用例 E2E-01，预置 `t-demo-01`）

| 时间 | 操作 | 台词要点 | 预期画面 |
|---|---|---|---|
| 0:00–0:30 | 开场 | 「一句话输入，系统产出可复核的整星方案：数字全部可追溯、可复算」 | 架构一页图 |
| 0:30–1:30 | P1 填入示例任务书 → 提交 | 展示约束字段 | 任务入队，跳转 P2 |
| 1:30–4:00 | P2 Trace 跟步骤 | 「S1 解析 → S2 检索先例 → S3 分解 → S4 参数 → S5 计算 → S6 校验」 | 时间线滚动，逐步入场 |
| 4:00–4:40 | 展开一条引用 | 「这个选型建议来自 NASA SST-SOA 第 X 章」 | 引用展开原文与链接 |
| 4:40–5:40 | 展开一条计算记录 | 「4.8 m² 是算出来的：公式、输入、commit 都在」 | CalculationRecord 详情 |
| 5:40–6:40 | P3/P4 门禁操作 | 「假设必须工程师确认」→ 点击 accept | GateModal → 时间线追加记录 |
| 6:40–7:40 | P5 下载 Word | 「每个数字带出处，附录可反查」 | 打开 Word + 附录引用表 |
| 7:40–9:00 | **拦截演示**（§3） | 「无出处的数字进不了文档」 | block 差异报告 + 409 |
| 9:00–10:00 | 导出 trace 回放 | 「全过程可回放、可复现」 | trace.jsonl / P2 回放 |

## 3. 拦截演示（高潮，对应 ADV-01）

执行：`make demo-adv`（以录制桩注入错误输出，可重复、耗时 <1 分钟）

1. 注入「太阳翼面积 5.2 m²，无计算过程」的 S4 桩输出
2. 系统动作：**要求计算请求 → S5 复算 → V2/V3 不一致 → block**
3. P4 展示差异报告（期望 4.8 vs 注入 5.2，含 evidence），转人工门禁
4. A10 下载被拒（409 `DOC_NOT_READY`）
5. 台词：「不是让另一个 Agent 去看一眼，而是让同一个量走一条**独立的计算路径**；证据链对不上就不准入稿」

## 5. 环境准备与回退

**演示前 30 分钟清单**：

- [ ] `make up && make check` 全绿
- [ ] `make seed`（含 `t-demo-01` / `t-demo-adv` 与录制桩）
- [ ] `make test-e2e` 预热一遍（E2E-01 通过）
- [ ] 浏览器预开 P2/P3 页签；Word 已装可打开
- [ ] 投屏分辨率检查；关闭通知

**回退链**：

1. 一级：`STUB_LLM=1` 桩模式（无网络依赖）
2. 二级：直接展示预录 trace 与 `artifacts/t-demo-01/document-v1.docx`
3. 三级：口述 + 架构图 + 差异报告截图
