## 1. 背景与目标

- 背景：面向卫星总体工程师的 AI 设计助手。工程师输入任务目标、轨道参数、卫星寿命、载荷参数、成像/通信需求、测控条件、整星约束，系统输出一份《卫星整星详细设计方案》Word。当前人工编制预算与交叉核对耗时且易错，历史资料散落、复用困难。
- 系统目标（可验证）：
  1. 一句话任务描述 → 完整 Word 方案，端到端 ≤ 10 分钟（含 1 次人工门禁）
  2. 文档中每个数值 100% 可追溯（计算记录 / 文档引用 / 显式假设），可被独立复算
  3. 校验闭环：无出处 / 不自洽 / 超余量的数字被拦截在正式文档之外
- 明确不解决：高保真轨道 / 热 / 结构仿真；采购级选型；多用户协同与权限体系。

## 2. 用户与典型场景

| 角色 | 目标 | 当前痛点 | 系统如何帮到 |
|---|---|---|---|
| 卫星总体工程师（主用户） | 快速产出可复核的整星方案 | 手工预算耗时、一致性难保证 | 自动生成 + 强制校验 + 全链路可追溯 |
| 评审者（演示观众） | 看清系统如何工作、数字为何可信 | 黑盒系统无法自证 | Trace 回放 + 拦截演示 |

典型任务（按优先级）：

1. 500km SSO 光学遥感小卫星：输入任务书 → 得到完整《卫星整星详细设计方案》
2. GEO 通信卫星（简版）：转发器参数 + 寿命约束
3. 载荷变更后的冲突检查：修订任务书 → 校验触发 warn/block → 走门禁

## 3. 功能范围

| # | 功能 | 本期 | 说明 / 不做的理由 |
|---|---|---|---|
| F1 | 任务书解析与需求澄清 | ✅ | 结构化输出 MissionRequest；歧义时追问 ≤ 3 轮 |
| F2 | 方案分解与设计参数草案 | ✅ | LLM 出草案，指标树结构与 id 由规则约束 |
| F3 | 质量 / 功耗 / 数据量预算 | ✅ | 公式与余量策略见 [06](./06-calculation-verification.md) |
| F4 | 测控数传与链路预算 | ⚠️ 简化模型 | 自由空间损耗 + 简化大气/雨衰；误差与假设在正文标注 |
| F5 | 轨道与覆盖分析 | ⚠️ 简化模型 | 二体 + J2 + 几何可见性；开源库交叉验证（ADR-0004） |
| F6 | 分系统配置与器件选型建议 | ⚠️ 只读候选 | 候选来自知识库（SST-SOA / 公开资料），必须标出处 |

| F8 | Word 技术文件生成 | ✅ | docxtpl 渲染 + 出处标注 + 校验报告（ADR-0005） |
| F9 | 对话式多轮改设计 | ❌ | 不确定性与成本不可控；以「修订任务书重跑」替代 |

## 4. 不做清单（冻结）

> 范围被挑战时先看这里。

- 不做无人工门禁的全自主生成 —— 总体参数需工程师确认，责任边界不可后移
- 不做全部分系统的深入设计 —— 本期聚焦总体与预算主线；结构 / 热仅做约束检查
- 不做高保真仿真（轨道全摄动 / 热 / 结构）—— 简化模型 + 误差声明，避免精度陷阱
- 不做自动选型写操作与采购级推荐 —— 只做只读候选，避免错误推荐担责
- 不做模型微调 —— 成本高、收益不明；用提示词 + 知识库替代
- 不做多租户 / 复杂权限体系 —— 演示级单用户 Token 足够
- 不做中文以外语种输出 —— 聚焦中文工程场景
- 不做三维可视化动画（对演示非必需）

## 5. 输入与输出

- **输入**（字段级定义见 [03 数据模型](./03-data-model.md)）：任务目标、轨道参数、卫星寿命、载荷参数、成像 / 通信需求、测控条件、整星约束
- **输出**：
  1. 《卫星整星详细设计方案》Word（章节清单见 [10](./10-doc-generation.md)）
  2. 任务 trace（jsonl，可回放）
  3. 机器可读校验报告（json）

## 6. 验收标准

> 每条可演示、可复现，对应 [11 测试计划](./11-test-plan.md) 的用例编号。

| # | 验收标准 | 验证方式 |
|---|---|---|
| A1 | 输入一句话任务描述，产出完整 Word，章节齐全、0 残留占位符、可下载 | 黄金用例 E2E-01 |
| A2 | 校验层拦住全部对抗用例（无出处 / 单位混用 / 不闭合 / 编造引用 / 无依据 / 陈旧参数） | 对抗用例 ADV-01~06（6/6） |
| A3 | 抽查 20 个文档数字，100% 可追到计算记录或引用或假设 | trace 检查 |
| A4 | 演示脚本 10 分钟内完整执行（含一次拦截演示） | [15 演示脚本](./15-demo-script.md) 彩排 |
| A5 | 单次任务端到端 ≤ 10 分钟、成本 ≤ ¥3（按主力模型口径） | trace 汇总统计 |

## 7. 非功能要求

- 性能：单次任务端到端 ≤ 10 分钟；单步 LLM 调用 ≤ 120 秒
- 成本：单次任务 ≤ ¥3；超 80% 告警，超限中断
- 可复现：固定语料 manifest + 模型版本 + 提示词版本 + 随机种子
- 可观测：全链路 trace 落 jsonl，可导出、可回放

## 8. 风险与假设

| # | 风险 / 假设 | 影响 | 应对 |
|---|---|---|---|
| R1 | 简化模型精度不足 | 结论可信度受质疑 | 误差范围与假设显式声明 + 开源库交叉验证 |
| R2 | LLM 输出不稳定 | 流程中断 | 结构化输出 + 修复重试 + stub 回归 + 门禁 |
| R3 | 范围膨胀 | 交付不完 | 第 4 节冻结清单；任何扩围走 ADR |
| R4 | 中文公开语料稀缺 | 检索质量差 | 公开资料打底 + 合成语料（标注 synthetic） |
| R5 | 演示环境 / 网络故障 | 演示失败 | 离线 Ollama 模式 + 预录 trace 回退 |

## 9. 里程碑（粗粒度）

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| M1 | 端到端骨架跑通 | 输入 → Word 可跑通（内容可粗糙，允许 stub LLM） |
| M2 | 计算与校验闭环 | E2E-01 / E2E-02 全过，ADV-01~03 可拦截 |
| M3 | 门禁与 Trace 完整 | 前端可用：trace 回放、参数评审、差异处置 |
| M4 | 演示就绪 | 15 脚本可执行 + 拦截演示 + A5 指标达标 |
