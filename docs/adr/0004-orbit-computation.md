# ADR-0004：轨道与覆盖计算路线

| 项目 | 内容 |
|---|---|
| 状态 | 接受 |
| 日期 | 2026-10-05 |
| 决策人 | 项目负责人 |
| 关联 | [06 计算与校验](../06-calculation-verification.md) |

## 1. 背景与问题

- 系统需要：轨道初步设计、地面站可见性、过境窗口与重访统计
- 约束：演示优先、依赖轻；同时要为「独立校验」提供可信的交叉验证路径
- 候选开源库现状：poliastro 已归档；satmad 停更；brahe 较新但活跃（MIT）；Tudat 成熟但重；GMAT 需外部进程

## 2. 备选方案

| 方案 | 描述 | 优点 | 缺点 |
|---|---|---|---|
| A（选定） | 自研简化模型为主（二体 + J2 长期项 + 几何可见性）；开源库仅做交叉验证 | 可控、轻依赖、覆盖逻辑贴合需求；生成 / 校验路径天然独立 | 精度受假设限制，需声明误差 |
| B | brahe 为主路径 | 少写基础力学 | 库年轻，API 稳定性待评估 |
| C | Tudat 为主路径 | 高保真、学术成熟 | 重依赖、学习曲线陡 |
| D | GMAT 外部脚本 | 贴近工程实践 | 集成成本最高，演示链路长 |

## 3. 决策与理由

- 主计算：自研简化模型（二体 + J2 长期项；最小仰角约束下的几何可见性；过境窗口与重访统计）
- 交叉验证：选用一个开源库（brahe / tudatpy / skyfield，开发期评估后确定）作为**独立复算路径**，只用于 V2 校验，不做主路径
- 理由：
  1. 覆盖 / 重访的业务逻辑（窗口统计、任务级简化假设）自写更贴合需求，误差与假设可显式声明
  2. 「自研模型算、库复算」天然满足校验独立性的要求，无需引入重型仿真
  3. 演示链路短、零重型依赖
- 明确放弃：本期不做高精度定轨、摄动全模型、姿态耦合轨道仿真

## 4. 影响

- 必须在 [06](../06-calculation-verification.md) 中声明模型假设与适用误差范围；文档中不出现「高精度」表述
- 交叉验证库需在开发期完成对拍测试（纳入 [11 测试计划](../11-test-plan.md) L1）
- 后续升级路径：将主路径替换为库实现时，需同步更新本 ADR 与 06
